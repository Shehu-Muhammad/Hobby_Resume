# 🎨 Hoo's Hobbies

A personal portfolio-style webpage showcasing hobbies, gaming achievements, books, shows, workouts, and projects.  
Built with **HTML, CSS, and JavaScript** for a simple, interactive design.

## 🚀 Features

- **Personal Branding**
  - Header with name and tagline
  - Click interaction (`alertNameClicked()`)

- **Gaming**
  - PSN Trophy Cabinet with platinum achievements
  - Current "Now Playing" game list
  - Gaming progress tracker

- **Learning & Growth**
  - Reading list of self-improvement books
  - Media queue (shows watched, movies to watch)
  - Media log for tracking progress

- **Lifestyle**
  - Workout split routine
  - Coding focus section
  - Ongoing/future project ideas

- **Old School Runescape**
  - Stats & links via Wise Old Man

## ⚡ Getting Started

Clone this repo:
```bash
git clone https://github.com/your-username/hoo-hobbies.git
cd hoo-hobbies
```

## 🛠️ Customization
- Update index.html with your own:

- Name & tagline

- Gaming trophies

- Current games, books, shows, projects, etc.

- Modify styles/main.css for custom colors and layout.

- Add more interactive features in scripts/index.js.
